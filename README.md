# Blender Batch Tools

Free, open-source Blender scripts for 3D artists and 3D-printing designers: batch turntable renders and batch STL export.

## Scripts

- `turntable_render.py` – renders a 360° turntable of every selected object
- `batch_stl_export.py` – exports each selected object as its own STL file

## How to use

1. Open your .blend file in Blender 4.x.
2. Select the objects you want to process.
3. Open the Scripting workspace, load a script, edit the settings at the top, and press **Run Script**.
